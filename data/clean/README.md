# Withheld prepared-data layer

Prepared rows are withheld because they are row-level derivatives of supplied
assessment records and the assessment did not provide redistribution
permission. This folder intentionally contains documentation only; cleaning or
renaming restricted rows would not make them public.

The [public source schema](../source-schema.md) describes the original logical
tables at an aggregate level. The public [analysis
workbook](../../analysis/workbook/Marketplace_Reliability_Aggregate_Analysis.xlsx)
uses aggregate evidence only and does not reproduce the private ETL pipeline.
