# Analysis workbook

[`Marketplace_Reliability_Aggregate_Analysis.xlsx`](Marketplace_Reliability_Aggregate_Analysis.xlsx)
is a formula-backed, aggregate-only workbook for this anonymized portfolio
edition. Its inputs are published count tables; formulas calculate the reported
rates and reconciliation checks. It contains no supplied, cleaned, or
row-derived operational records.

The workbook does not reproduce the private ETL pipeline. For definitions,
denominators, scope, and limitations, read the [evidence
record](../eda-methodology-and-evidence.md) and [source
schema](../../data/source-schema.md).
