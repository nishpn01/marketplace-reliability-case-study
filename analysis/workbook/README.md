# Analysis workbook

[`Marketplace_Reliability_Aggregate_Analysis.xlsx`](Marketplace_Reliability_Aggregate_Analysis.xlsx)
is the formula-backed, aggregate-only workbook for this anonymized portfolio
edition. Download it to view it in Excel, OnlyOffice, or another spreadsheet
application; GitHub does not render `.xlsx` files in the browser.

The workbook contains eight sheets:

1. a screenshot-ready portfolio summary;
2. the raw-to-clean-to-mart preparation and publication boundary;
3. the complete aggregate exploratory screening tables;
4. the selected booking-timing analysis;
5. the time-aware HCP-history screen and threshold sensitivity;
6. the analysis path and dispositions;
7. formula-driven reconciliation checks; and
8. the methodology, definitions, and disclosure notes.

Rates are calculated from displayed aggregate numerators and denominators. The
workbook does not reproduce the private row-level ETL pipeline or include
supplied, cleaned, or joined operational records. For the narrative evidence
record and public source fields, read the [EDA record](../eda-methodology-and-evidence.md)
and [source schema](../../data/source-schema.md).
